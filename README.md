# EmotiLog

**Java · Android Studio · XML**  
**Course:** University of Alberta · CMPUT 301 Software Engineering  
**Project type:** Individual Android assignment

## Overview

An Android application for selecting and logging emotions. Eight emoji buttons let a user record an emotion with a timestamp. A log screen filters entries by date and summarizes the number of entries for each emotion. The original implementation keeps its log in memory.

## Repository contents

- `app/src/main/java/com/example/emotilog/` — original Java model and activities.
- `app/src/main/res/` — original Android layouts and resources.

## Running

Open the project in Android Studio, install the appropriate Android SDK and Gradle dependencies, and configure the services required by the original implementation. Build/run behavior has not been verified in the current environment.

**Configuration:** `local.properties`, any `google-services.json`, private keys, and user data are deliberately excluded. Supply your own authorized Firebase project configuration where required. Do not commit credentials or personal information.
